# Mog Battle

ИИ-оценка внешности, стиля одежды и их синергии. Телефон (Android) и ПК (Windows). Ставится через **Winter Hub**.

- **Мог-батл** — твоё фото против фото соперника: кто где сильнее по каждой категории, вердикт и советы, как забрать реванш.
- **Оценка** — одно фото: оценка по категориям, сильные и слабые стороны, потенциал и конкретные советы.
- Три режима: **Внешность**, **Стиль** (одежда, цвета, посадка), **Синергия** (как одежда подходит именно тебе).
- **История** с графиком прогресса, тон оценки (мягко / честно / без пощады).

Оценку делает Google Gemini — нужен бесплатный API-ключ из Google AI Studio (вставляется в «Настройках»).

Сборки — в Releases: `Mog-Battle.apk` (телефон), `Mog-Battle-Setup.exe` (ПК).
